# ClanForge Frontend

React + Vite frontend for the Clan Management System.

## Setup

```bash
npm install
npm run dev
```

Runs on http://localhost:5173
Proxies /api calls to Spring Boot on http://localhost:8080

## Pages
- `/login` - Sign in
- `/register` - Create account
- `/dashboard` - View & manage all clans
- `/clans/:id` - Clan detail + member management
- `/stats` - Global leaderboard & stats
